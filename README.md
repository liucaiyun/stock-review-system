# 股票复盘系统 (Stock Review System)

一个面向 A 股个人投资者的**本地复盘工具**：输入股票代码，用常见日线策略标买卖点，做复盘笔记和统计图。成交可从同花顺客户端导出 CSV 一键导入。

> 本工具仅供个人学习与复盘，不构成投资建议。

## 项目介绍

市面上的行情软件负责看盘、券商软件负责下单，但**"复盘"这个环节几乎没有产品认真做过**——而它恰恰是个人投资者唯一能完全掌控的环节。

这个系统把复盘变成收盘后 10 分钟的固定动作：输入代码，9 套日线策略自动在 K 线上标出买卖点，并给出**扣掉手续费与滑点、按次日开盘成交、再与沪深300 比超额**后的真实统计（不这样做的话，回测胜率只是好看的假数字）；持仓页实时盯住每只股票的 -8% 纪律线，破线自动记事件，逼你在「已止损」和「硬抗」里二选一，月底用「纪律执行率」和「硬抗平均多亏」两个数字直面自己的执行问题；每日记一笔总资产与出入金，**剔除出入金**的净值曲线、最大回撤、对比沪深300 一目了然。行情走东方财富公开接口，持仓、成交、笔记全部存在本地 H2 数据库——不注册、不登录、不上传。

## 项目亮点

- **开箱即用**：Spring Boot + H2 文件库，无需安装数据库，双击 `start.bat` 即可运行
- **止损纪律闭环**：跌破自定义纪律线（默认 -8%）自动记录事件 → 强制选择「执行止损 / 硬抗」→ 统计纪律执行率和硬抗平均多亏，用数据治"手痒"
- **策略信号 + 回测**：K 线上标注买点/卖点/警示；9 套策略回测 5/10/20 日**净胜率**（已扣双边佣金/过户费/印花税/滑点、按**次日开盘**成交）并对比沪深300 看**超额**；再加**逐笔交易模拟**——ATR 止损、1R 保本、2R 跟踪、时间与卖点出场，输出**R 倍数与期望值**（胜率 35% 但盈亏比 1.5 是赚钱的，胜率 70% 但盈亏比 0.2 是亏钱的）；分歧日自动标记
- **本地私有**：行情走东方财富公开接口（带 5 分钟缓存），持仓与成交数据全部存在本地 H2 库，不上传任何第三方

## 能做什么

| 模块 | 说明 |
|------|------|
| 今日复盘 | 上证/深成/创业板/沪深300 快照、自选当日信号、市场笔记、个股点评、错题本标签 |
| 自选股 | 输入代码或名称加入观察池，看现价和涨跌幅 |
| 持仓 | 手动录入数量、成本价/成本金额，看市值、浮动盈亏、仓位占比、纪律线（默认 -8%，可按只设置幅度）、行业集中度 |
| 止损纪律闭环 | 破纪律线自动记事件 → 执行止损/硬抗二选一 → 统计纪律执行率、硬抗平均多亏、硬抗结局分布与硬抗中实时代价 |
| 风险与仓位 | **ATR 口径**的单笔风险（股数 × 2×ATR）、按风险预算反推的建议股数、占总资金（含现金）的仓位占比，以及单票/行业/持仓数/总仓位的硬性上限与「纪律线太紧/太松（不足 1 个或超过 4 个 ATR）」检查 |
| 净值曲线 | 每日记一笔总资产 + 当日出入金 → 剔除出入金的净值曲线、最大回撤、对比沪深300、超额收益、年化与夏普 |
| 策略信号 | K 线 + MA，标买点/卖点/警示；9 套策略回测 5/10/20 日净胜率与超额（扣费、次日开盘成交、对比沪深300）；**逐笔交易模拟**给出每套打法的 R 倍数、期望值、盈亏比、最大连亏与 R 曲线回撤，并可点开逐笔明细核对；**样本外验证**（walk-forward）用「过去挑参数、未来看结果」检验这些期望值是否可信；卖点不做空，只衡量卖完之后跌了多少；分歧日自动标记 |
| 到价提醒 | 破纪律线、计划触止损/目标/超期、待处理事件；顶部横幅在**进入页面或处理事件后**刷新（当前没有定时轮询，盘中价格变动不会自动弹提醒） |
| 做T/仓位计算器 | 做T 摊成本试算（含昨高昨低/均价/MA 参考位）；风险预算法算可买股数 |
| 统计图 | 净值曲线、策略胜率、纪律执行率、错题本、持仓盈亏、月度买卖金额、复盘情绪 |
| 成交录入 | 手工记买/卖流水；买入时可**关联已有的进行中计划**（下拉自动带出这只票的计划，默认挂最近那条），也可以顺手新建计划并填止损/目标/天数；卖出时自动结束该股票的计划 |
| 执行偏差量化 | 用成交流水还原每一笔真实交易（含加仓），和交易计划逐项对账：追高入场、超过计划止损、亏损加仓**都折成钱**；输出「按计划执行 vs 违规」的期望值对照；并把「已执行止损」与真实卖出成交对账，抓出没有对应卖出的自报止损 |
| 同花顺导入 | 导入客户端导出的成交明细 |

### 内置策略

自有策略（面向实盘的保守打法）：

1. **稳健版（MY_STEADY）**：6 零件（双均线/MACD/RSI/布林/突破/量价）≥2 个同向成强信号；分歧日（振幅>8% 且实体<2%）只警示不建仓
2. **超稳健版（MY_ULTRA）**：稳健版 + 趋势门（MA20>MA60 且收盘>MA20）才记买点；收盘跌破 MA20 记强卖点

学习策略（教科书对照）：

1. **均线金叉死叉**：MA5 上穿/下穿 MA20
2. **均线多空排列**：MA5>MA10>MA20 形成多头，反之空头
3. **MACD 金叉死叉**：DIF 与 DEA 交叉
4. **RSI 超买超卖**：RSI 上穿 30 / 下穿 70
5. **KDJ 金叉死叉**：K 与 D 交叉，结合 J 值过滤
6. **布林带突破**：收盘跌破下轨 / 升破上轨
7. **放量突破**：成交量 > 20 日均量 1.5 倍，且收盘创新高

综合结论：当日 **2 个及以上策略同向** 标「偏多/偏空」。

## 同花顺账号为什么不能直接登录

同花顺**没有**对个人用户开放官方持仓/成交 API，用账号密码去对接属于非官方抓取，不安全也不稳定。本系统用两条可行路径：

1. **行情**：东方财富公开行情（K 线、实时报价），用于策略。
2. **账户成交**：同花顺客户端导出成交明细 → 本系统「同花顺导入」。

导出参考：交易 → 查询 → 成交 → 导出。表头尽量包含：成交日期、证券代码、操作（或买卖标志）；数量/价格/金额/名称会自动匹配。编码支持 GBK、UTF-8。

## 快速开始

环境要求：**Java 17+** 和 **Maven**。

```bat
:: 方式一：源码直接跑
start.bat

:: 方式二：打包后运行
build.bat
java -jar target\stock-review-system-1.0.0.jar --server.port=8088
```

浏览器打开 http://localhost:8088 即可使用。

- 数据存在项目目录 `data/`（H2 文件库），不必安装 MySQL
- H2 控制台：http://localhost:8088/h2 （JDBC URL 见 `application.properties`，用户 `sa`，密码空）

## 使用建议

1. 在「持仓」手填代码、数量、成本价（已在自选里的同一代码会自动合并）。
2. 「自选股」只记观察池；要记买卖流水用「成交录入」（在那一页还能把它挂到已有的交易计划上，执行偏差报表才对得准）。
3. 「策略信号」输入代码，看 K 线上的三角买/卖点，对照回测胜率。
4. 收盘后到「今日复盘」写对错和明日计划。
5. 若用同花顺实盘，也可导出成交 CSV 批量导入。

## 回测体检（可选）

想验证「这套策略到底是不是真的能赚钱」，跑一次体检工具：

```bat
powershell -File tools\backtest-audit.ps1
```

它会：① 先用**合成 K 线自检交易模型**（21 条断言，例如「初始止损必须亏正好 1R」「跳空跌破止损必须比按止损价更亏」「一次只持一笔」「平盘行情下任何参数都赚不到钱」）；② 下载 24 只样本股 + 沪深300 的前复权日线（腾讯接口）；③ 调用**项目自身的**策略代码生成信号；④ 用独立口径复算，输出报告到 `tools\backtest-audit-data\report.txt`。

报告里有：每个策略的毛收益、扣费滑点后收益、同期沪深300、**净超额**；一个**无条件基线**（不挑信号、随便哪天买入持有同样天数）；**逐笔交易的 R 倍数与期望值**（胜率/盈亏比/最大连亏/累计R/R 曲线回撤/出场分布）；**样本外验证（walk-forward）**——时间轴切 4 段，每折只用过去挑参数、再拿去跑未来那一段，并给出 t 值判断「期望值是否和 0 分得出来」；**参数敏感性**；以及两个容易被忽略的关键检验——**6 个「共振零件」之间的相关性**（相关性高说明它们其实是同一个零件）、**买点次日开盘相对信号日收盘的缺口**（衡量回测有没有系统性乐观）。

还有一组对照：同一批买点、同一套 ATR 止损，**关掉策略自己的卖点**后会更好还是更差——实测 9 套策略里有 3 套的卖点明显在过早砍掉盈利单（稳健版去掉卖点后期望值从 +0.062R 升到 +0.188R）。

⚠️ **这个工具存在的意义是「否证」**：它在样本外明确告诉你这 9 套策略里没有一套表现出可证明的正期望。别跳过它去用真钱试。

它只读，不改源码、不写数据库。App 里「统计图」页也有同样的样本外验证（按钮触发，用你自己自选池的缓存日 K）。
