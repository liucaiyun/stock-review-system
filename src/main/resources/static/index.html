同花顺账号说明

同花顺没有对个人账号开放官方登录/持仓 API，第三方程序不能安全地用你的同花顺账号密码去拉券商持仓。本系统采用可行替代：
  1. 行情与 K 线：东方财富公开行情（沪深京 A 股/ETF），用于策略买卖点。
  2. 手动录入：到「持仓」记数量和成本，到「成交对照」记买卖流水，不连同花顺也能用。
  3. 批量导入：同花顺客户端 交易 → 查询 → 成交 → 导出 CSV，在本页导入。

表头需能识别：成交日期、证券代码、操作/买卖标志；数量、价格、金额、名称会尽量自动匹配。编码支持 GBK / UTF-8。
