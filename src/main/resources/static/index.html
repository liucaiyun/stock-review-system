成交对照信号

用全部 7 条常用策略的买/卖点，对照你实际成交：当天打中、信号后追、提前做、偏晚，还是靠近反向信号。用于复盘纪律，不是买卖建议。

执行偏差（计划 → 成交闭环）

用成交流水还原你真实做过的每一笔（买入建仓 → 全部卖出），再和交易计划逐项对照： 追高入场、超过计划止损、亏损加仓这三项能折成钱；未达目标、超期持有只标差距。 「已执行止损」必须能在流水里找到对应卖出才算核实通过——执行率不该由自报决定。

同花顺账号说明

同花顺没有对个人账号开放官方登录/持仓 API，第三方程序不能安全地用你的同花顺账号密码去拉券商持仓。本系统采用可行替代：
  1. 行情与 K 线：东方财富公开行情（沪深京 A 股/ETF），用于策略买卖点。
  2. 手动录入：到「持仓」记数量和成本，到「成交录入」记买卖流水，不连同花顺也能用。
  3. 批量导入：同花顺客户端 交易 → 查询 → 成交 → 导出 CSV，在本页导入。

表头需能识别：成交日期、证券代码、操作/买卖标志；数量、价格、金额、名称会尽量自动匹配。编码支持 GBK / UTF-8。
